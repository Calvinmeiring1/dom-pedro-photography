# Dom Pedro Photography

Luxury photography website built with React + Vite.

## Run locally
npm install
npm run dev

## Build
npm run build

## Cloudflare Pages
Connect this repository to Cloudflare Pages:
- Build command: `npm run build`
- Build output directory: `dist`

## Replace before launch
- Replace the Unsplash image URLs in `src/main.jsx` with the photographer's own licensed images.
- Change the email and Instagram links.
- Update the about copy, location and pricing/booking details.
